# View Assumptions

Give a plain recap of the analytical foundation for this project, so the user (or a future session) can see at a glance what's solid and what's provisional.

## Structure the answer as:

**Data sources used**
- List each file/document relied on so far (e.g. `fy2026-27-managers-recommended-budget.pdf`), with what it does and doesn't cover.

**Key assumptions made**
- Any interpretive choice, e.g. "treating the Solid Waste division total as a proxy for yard waste costs, since no yard-waste-specific line item exists in the budget."
- Any gap filled by inference rather than stated fact.

**Known gaps / unresolved**
- What's still missing (e.g. the actual fee schedule with cart/pickup fee amounts) and why it matters to the conclusion.

**Scope boundaries**
- What this analysis does and doesn't claim to answer (e.g. it evaluates whether the *cost side* looks reasonable, not whether the specific dollar fee amount is fair, since the fee amount itself hasn't been located).

Keep this factual and skimmable — it's a status check, not a new round of analysis.
