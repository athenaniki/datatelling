# Suggest Next Steps

Look at what's been done in this project so far (source docs read, tables extracted, charts made, gaps identified — check `README.md` and recent conversation for current state) and propose 2-4 concrete, prioritized next actions. Not a generic list — specific to what's actually missing.

## How to prioritize

1. **Blocking gaps first**: if the core deliverable (evaluating the yard waste cart fee) can't be finished without a specific document (e.g. the Town's Fee Schedule resolution), that's the top suggestion — and say how to get it (e.g. "check chapelhillnc.gov's Solid Waste page, or the budget ordinance's fee schedule attachment").
2. **Cheap wins next**: things doable right now with existing data, e.g. "chart the Solid Waste division's 3-year expenditure trend" or "compute cost-per-collection-stop if subscriber counts are available elsewhere."
3. **Validation steps**: if conclusions have been drawn but not verified, suggest running `/spot-check` or `/verify`.
4. **Presentation**: once analysis is solid, suggest `/writeup` or `/six-charts` to package it.

Keep each suggestion to one line: the action and why it matters now. Don't suggest more than 4 things — this should be a short nudge, not a project plan.
